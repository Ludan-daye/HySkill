## 2. 新的论文定位（作者已确认）

**主张**：想象提升候选池质量；路由器按领域选择想象粒度；整体显著优于 HyDE 原版。完整 SKILL.md 结构本身不再作为卖点。

**下游分两档**：
- Hy+Select：精度优先，需要一次额外的 LLM 调用。
- Gated：不需要额外调用，七个模型都能用。

**不能写的说法**：
- 优于 LLM 重排的排序能力。top-1 没有检测到差异。
- Hy+Rerank 显著优于 BM25+Rerank。CI 为 [−0.03, +5.58]。
- 路由优于"按领域事后挑出的最佳配置"。没有检测到差异。
- 权重逐文件一致。只能写"分词器和模板哈希一致，同技能题准确率差异在噪声内"。

## 4. 必须改正的口径错误（用改正版）

1. **图 `fig:retrieval-recall-by-model` 的平均面板 (h)**
   - 问题一：BM25 和重排曲线混入了 Qwen3.5-4B 的 SR-Agents BM25，R@50 从 .688 被抬到 .709。
   - 问题二：路由曲线是 7 个模型的平均，基线曲线是 5 个模型的平均，违反"七模型不能和五模型比"的规则。
   - 改法：用 4 个 FastBM25 模型同口径重画。
2. **正文第 279 行"Qwen3.5-4B 的 BM25 nDCG@10 .438"**：这个数用的是 SR-Agents 打分器，不能和表里的 .362（FastBM25）直接比较。注明打分器不同，或者改用 FastBM25 的数。
3. **E1 / E4 的 BM25 列**：已在第二版中改正，即 E1 用共享 FastBM25 候选，E4 只用 4 个模型。直接引用第二版。
